# Sphere League — UI Kit Visual Direction
Date: 2026-11-19
Status: Owner approved concept direction; production-ready separated sprites not yet delivered.

## Approved
Neon-edged chunky comic-style UI, dark navy base, cyan/blue/purple/gold team and effect accents, clear readable typography and thick outlines. Include primary, secondary, special and disabled buttons in normal and pressed states, reusable panel, stat bars, utility icons and badge. Separate production components with transparent background; game renders labels and values dynamically. Design for 180×320 mobile canvas and usable tap targets.

## Important owner note — possible future art direction revision
Current artwork has a lot of literal underwater imagery, especially coral. Warren likes the current UI and approves moving forward, but wants to explore a stronger **technology + fantasy** fusion later, with less coral and fewer repeated underwater decorative motifs. This is an aesthetic reference to the feel of classic underwater fantasy sports, **not** a request to copy any existing game's proprietary artwork. Prefer original Sphere League designs. Do not initiate a wholesale redesign now: prioritize testing and implementation, then revisit visual balance based on gameplay.

## Implementation
Use the approved concept as reference, not as a finished production atlas. Split button states and panel pieces, keep interface content data-driven, and validate contrast and touchability on phone.
